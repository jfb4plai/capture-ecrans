1. Installer (une seule fois)

  1. Téléchargez le .zip depuis la page de téléchargement.
  2. Clic droit › Extraire tout… puis double-clic sur Capture-ecran-PLAI.exe dans le dossier extrait.
  3. Si Windows affiche « Windows a protégé votre ordinateur » : Informations complémentaires › Exécuter quand même (le programme n'est pas signé).

Rien n'est envoyé sur Internet.

Où sont mes captures ? Au premier lancement, le programme crée sur votre bureau un dossier « Capture-ecran-jfb4plai » (avec le logo jfb4plai) et l'ouvre. Chaque série de captures y a son sous-dossier (date et heure). Le chemin est toujours affiché en haut de la fenêtre : cliquez dessus pour ouvrir le dossier. Dans chaque série : les images annotées, un dossier originales (sans annotation), audio, et vos exports (document.docx, fiche_pas_a_pas.html, video).

⚠ Bureau synchronisé (OneDrive…) : sur beaucoup d'ordinateurs, le bureau est copié automatiquement dans le cloud de Microsoft. Si vos captures peuvent montrer des noms ou des écrans d'élèves, choisissez un autre dossier (Réglages…) ou le choix « Documents » proposé au premier lancement. Le programme vous avertit quand il détecte ce cas (détection indicative : en cas de doute, vérifiez vous-même).

2. Photographier un menu déroulant

  1. Lancez le programme (une petite fenêtre s'ouvre ; vous pouvez la réduire).
  2. Ouvrez votre menu comme d'habitude (clic sur Fichier, clic droit…).
  3. Sans cliquer ailleurs, appuyez sur le raccourci :
RaccourciEffet
Ctrl+Maj+F9tout l'écran
Ctrl+Maj+F10vous choisissez une zone (le menu est déjà « figé »)
Ctrl+Maj+F11la fenêtre active seulement
Ctrl+Maj+F12démarre / arrête la série de clics

Un bip confirme la capture. Sur un portable, ajoutez la touche Fn si besoin. Les raccourcis se changent via Réglages… (évitez Ctrl+Alt : c'est la touche AltGr du clavier belge).

Si le raccourci ne marche pas : bouton « Dans 3 secondes », puis ouvrez votre menu pendant le décompte. Le pointeur est dessiné avec un halo jaune pour montrer où vous avez cliqué (désactivable).

3. La série de clics (une capture numérotée par clic)

Idéal pour expliquer une manipulation : faites-la une fois, le programme prend une image à chaque clic.

  1. Cliquez sur ● Enregistrer mes clics (ou Ctrl+Maj+F12). La fenêtre se réduit.
  2. Faites votre manipulation normalement. Un bip = une étape enregistrée. Chaque image reçoit un cercle rouge autour du clic, une pastille numérotée et la légende « Cliquez ici ».
  3. Arrêtez avec Ctrl+Maj+F12. Évitez de cliquer sur la barre des tâches pour rouvrir la fenêtre : ce clic serait enregistré.
  4. Améliorez chaque étape (double-clic sur la ligne) : légende, flèche, voix.

Moment de l'image : juste avant le clic (recommandé : on voit le menu ouvert et le pointeur sur l'élément à cliquer) ou 0,5 s après (on voit le résultat). Un double-clic est fusionné en une seule étape. Seuls les clics gauche et droit sont enregistrés (ni glisser-déposer, ni clavier). Après avoir supprimé ou déplacé des étapes : bouton ↻ Renuméroter.

4. Annoter, légender, enregistrer sa voix

L'éditeur s'ouvre tout seul après chaque capture. Choisissez un outil, une couleur, une taille, puis glissez sur l'image.

OutilUsage
➚ Flèchemontrer un bouton (Maj = flèche bien droite)
▭ Cadre · ◯ Ovale · ▮ Surlignerentourer, mettre en évidence
T Textecliquer puis écrire
① Numéroposer 1, 2, 3… pour les étapes
✎ Crayondessin libre
▦ Masquerpixelliser un prénom, un nom d'élève, une adresse (RGPD)
✂ Recadrergarder seulement une zone
☝ Déplacerdéplacer un objet (Suppr pour l'effacer)

Ctrl+Z annule, Ctrl+Y rétablit. Copier l'image puis Ctrl+V dans Word, Teams ou un courriel. Ouvrir dans Paint fixe les annotations dans l'image puis ouvre Paint (vous ne pourrez plus les déplacer dans notre éditeur).

Masquer ne protège que l'image enregistrée : relisez toujours avant de partager.

La légende (en bas de l'éditeur) devient le sous-titre de la vidéo : une phrase courte par étape, à l'impératif (« Cliquez sur Fichier »).

Ma voix : 🎙 Enregistrer ma voix, lisez la légende, ⏹ Arrêter, ▶ Écouter pour vérifier, ✖ Effacer pour recommencer. Il faut un micro autorisé dans Paramètres Windows › Confidentialité › Microphone. Parlez dans une pièce calme, à 20 cm du micro.

5. Fabriquer une fiche, un document Word ou une vidéo

Dans la fenêtre principale, réorganisez les captures avec ▲ ▼, puis :

  • 📝 Document Word : document.docx (A4), un titre « Étape n », la légende et l'image. Police Verdana 12, vrais titres Word (navigation, lecteurs d'écran) et texte alternatif sur chaque image.
  • 📄 Fiche HTML/PDF : page web numérotée, imprimable ou « Enregistrer au format PDF ».
  • 🎬 Vidéo : crée le dossier video dans la série.

Option : dans Réglages…, cochez l'ajout du logo jfb4plai en haut des fiches et documents.

6. Créer la vidéo sous-titrée

Dernière vérification des informations sur Clipchamp : 16/10/2026, par recherche web (sources secondaires). À contrôler dans l'application, les menus évoluent.

Voie 1 — directe, un seul clic

Le dossier video contient : image_001.png… (1920×1080, sous-titre incrusté), soustitres.srt, durees.txt, voixoff.wav si vous avez enregistré votre voix, et video.mp4 si le programme ffmpeg est présent. La durée de chaque image suit la longueur de la légende (3 à 15 s) ; avec une voix, l'image reste au moins aussi longtemps que la parole (+ 0,6 s) : elle n'est jamais coupée.

Voie 2 — sans ffmpeg : assembler dans Clipchamp (Windows 11)

  1. Ouvrez Clipchamp › Créer une vidéo.
  2. Glissez les image_001.png… sur la ligne de temps, dans l'ordre, et réglez leur durée (voir durees.txt).
  3. Glissez voixoff.wav sous les images : elle est déjà synchronisée si vous gardez les durées par défaut.
  4. Exporter › 1080p : fichier MP4 (l'export 1080p sans filigrane de la version gratuite est indiqué par des sources secondaires ; à vérifier).

Les sous-titres sont déjà dans les images : inutile d'importer le .srt (je n'ai pas pu confirmer que Clipchamp accepte cet import).

Voie 3 — obtenir le MP4 automatiquement

Le programme cherche ffmpeg tout seul (PATH de Windows, installations winget, Chocolatey, Scoop, C:\ffmpeg). S'il ne le trouve pas alors qu'il est installé : Réglages… › ffmpeg.exe › Parcourir… ; pour savoir où il se trouve, tapez where ffmpeg dans une invite de commande. S'il n'est pas installé : winget install Gyan.FFmpeg, puis fermez et rouvrez le programme. Ou placez ffmpeg.exe à côté de Capture-ecran-PLAI.exe. Faites valider l'installation par votre service informatique.

Conseils pour de bonnes vidéos

  • Une idée par écran, 6 à 12 mots de légende, verbes d'action.
  • 8 à 10 écrans au plus ; plusieurs courtes vidéos plutôt qu'une longue.
  • Masquez (▦) toute donnée d'élève avant de partager.
  • Pour des élèves à besoins spécifiques : texte blanc sur bande noire (contraste élevé), phrases courtes, et proposez aussi la fiche imprimée. Votre voix double l'information écrite.

7. Problèmes fréquents

ProblèmeSolution
« Raccourci déjà utilisé »changer le raccourci dans Réglages…
Le menu se ferme avant la captureutiliser « Dans 3 secondes »
« Impossible d'utiliser le micro »autoriser le micro dans Windows et vérifier qu'il est le micro par défaut
Aucune étape enregistrée avec la série de clicsun antivirus ou une règle d'école peut bloquer l'écoute des clics : utilisez les captures par raccourci
Rien dans le presse-papierscocher « Copier aussi dans le presse-papiers »
Image décalée ou floue avec le zoom d'écran à 125 %signalez-le avec votre version de Windows

Limites connues : écrit pour Windows ; non testé sur Mac ou Linux. Une fenêtre exécutée « en administrateur » peut ne pas laisser passer les raccourcis.
